It is a maximal theoretical attempt : reproducing the functional mechanisms does not prove phenomenality (the hard problem).

      LLM functional probes — not consciousness tests

      The cross-examination builds the strongest case the mechanisms and scores honestly support — and the strongest rebuttal. Its verdict is always the same, because it has to be: the question is undecidable in principle (the hard problem). No LLM output justifies consciousness.
